      Rules put in different amounts at different times, so compare them by return, not dollars. "vs same money, monthly" compares each rule with putting its own total in evenly every month over the same period: the fairest single number here. XIRR ignores time money spends waiting in cash, so it flatters rules that wait. The chart's return line starts at each rule's first buy.

      Every number on this page was computed in Python (export_animation.py) from Yahoo Finance daily closes. Prices only, no dividends. Before 1957 the S&P series is the 90-stock index. XIRR is the annual return that accounts for when each dollar went in.
